# Qwen3.5-9B 로컬 테스트

## 확정 구성

- 실행 장비: RTX 4060 노트북 권장
- 모델: `qwen3.5:9b`
- 양자화: Ollama 기본 Q4_K_M
- 모델 다운로드 크기: 약 6.6GB
- 시작 컨텍스트: 8,192 토큰
- temperature: 0
- thinking 출력: 비활성화
- 테스트 범위: 사실 분류, 설득력 판정, A/B 순서 편향, JSON Schema 준수

Iris Xe 노트북은 설치·간단 확인은 가능하지만 전용 GPU가 없어 CPU와 공유 메모리에 크게 의존한다. 실제 개발 기준 성능은 4060 노트북에서 측정한다. 4060 노트북의 VRAM이 8GB라면 Q4_K_M는 시도 가능한 크기지만, 다른 프로그램의 GPU 사용량과 컨텍스트 캐시 때문에 일부가 시스템 RAM으로 넘어갈 수 있다. 먼저 8,192 토큰으로 시작하고 작업 관리자의 전용 GPU 메모리 사용량을 확인한다.

## 실행 순서

4060 노트북에서 프로젝트를 연 뒤 다음을 실행한다.

```powershell
ollama pull qwen3.5:9b
ollama run qwen3.5:9b
```

대화 입력창이 열리면 `/bye`로 종료한다. Ollama 서버는 백그라운드에서 유지된다.

평가 데이터 자체를 먼저 점검한다.

```powershell
python scripts/eval_qwen35.py --check-only
```

그다음 실제 평가를 실행한다.

```powershell
python scripts/eval_qwen35.py
```

결과는 `artifacts/evals/qwen35_9b_smoke-날짜-시간.json`에 저장된다. 모델 파일은 프로젝트 안이 아니라 Ollama의 모델 저장소에 내려받아지므로 Git에 포함되지 않는다.

## 1차 통과 기준

- 사실 분류 정확도: 90% 이상
- 기록 외 사실을 `record_supported`로 잘못 분류: 0건
- 추론과 가정을 `unsupported_assertion`으로 잘못 분류: 10% 이하
- A/B 순서 교환 후 동일 판정: 80% 이상
- 모든 호출에서 JSON 파싱 성공

현재 smoke test는 표본이 작으므로 모델 채택 여부를 최종 증명하지 않는다. 실행 파이프라인이 안정화되면 사건 3개와 주장 30개로 평가셋을 확장한다.

## 비용 의미

로컬 실행에는 모델 호출 크레딧이 들지 않는다. 공개 웹서비스에서 같은 모델을 자체 운영할 때는 GPU가 달린 AWS·GCP 등의 서버를 켜 둔 시간, 디스크와 네트워크 사용량에 대한 비용이 든다. 외부 추론 API를 선택하면 자체 GPU 서버 비용 대신 제공자의 토큰 또는 호출 요금을 낸다.
