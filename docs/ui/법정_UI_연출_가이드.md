# 법정 웹게임 UI·연출 가이드

> 상태: UI 기준 시안 v1.0  
> 확정일: 2026-09-29  
> 기준 이미지: [courtroom-game-flow-concept-v1.png](./courtroom-game-flow-concept-v1.png)

## 1. 확정한 시각 콘셉트

- 아늑하고 단순한 2D SD 캐릭터 스타일
- 크림색 벽, 밝은 목재, 짙은 갈색 외곽선
- 검사 측은 muted terracotta, 변호인 측은 muted navy-blue
- 명암과 그라데이션은 최소화하고 평면적인 색면을 사용
- 캐릭터와 가구의 세부 묘사는 줄이고 표정과 실루엣을 크게 표현
- 창과 말풍선은 같은 크림색 재질, 둥근 모서리, 가는 갈색 테두리를 사용
- 화려한 법정 장식, 과도한 아이콘, 복잡한 배경 소품은 사용하지 않음

기준 이미지는 삭제하거나 덮어쓰지 않는다. 이후 수정본은 `v2`, `v3`처럼 별도 파일로 저장한다.

## 2. 법정 배치

관객석에서 재판부를 바라보는 시점을 사용한다.

```text
                  [재판장]
              높은 단상 · 중앙

       [검사]                    [변호인][피고인]
       화면 왼쪽                    화면 오른쪽

                     카메라
```

- 재판장은 화면 상단 중앙에 둔다.
- 검사석은 화면 왼쪽, 변호인과 피고인석은 화면 오른쪽에 둔다.
- 게임의 주인공은 검사와 변호인이지만 피고인은 변호인 옆에 작은 보조 캐릭터로 남긴다.
- 캐릭터 배치는 모든 페이즈에서 고정한다.

## 3. 전체 페이즈

```text
Phase 1 사건 확인·진영 선택 (60초)
  → 창이 아래로 내려감
재판장 개정 선언
  → Phase 2 주장 작성 (180초)
  → 입력 창이 아래로 내려감
Phase 3 검사 의견 진술
  → 변호인 의견 진술
  → 재판장 변론 종결
  → 판정 말풍선
  → 변론 판정 결과 창
```

실제 형사공판의 최종 의견 진술 순서를 참고해 플레이어 진영과 관계없이 검사가 먼저, 변호인이 다음에 말한다.

## 4. Phase 1 — 사건 확인 및 진영 선택

### 화면

- 법정 배경을 어둡게 처리하고 화면의 약 80%를 사건 설명 창으로 덮는다.
- 창 상단 왼쪽: `1단계 · 사건 확인`
- 창 상단 오른쪽: `01:00`
- 본문: 사건명과 확정된 사실을 큰 글씨로 표시
- 하단: `검사 선택`, `변호인 선택` 버튼

### 선택 후 연출

1. 선택된 버튼이 짧게 강조된다.
2. 사건 창이 아래 방향으로 내려간다.
3. 배경의 어두운 막이 사라진다.
4. 재판장 캐릭터가 한 번 고개를 들고 말풍선을 표시한다.

### 재판장 문구

```text
지금부터 「{사건명}」 사건에 대한 공판을 시작하겠습니다.
```

게임용 사건번호를 화면에 사용하는 경우:

```text
지금부터 {사건번호} 「{사건명}」 사건에 대한 공판을 시작하겠습니다.
```

`재판을 시작합니다`보다 `공판을 시작하겠습니다`를 기본 문구로 사용한다.

### 제한시간 종료

- 시간 종료 10초 전부터 타이머만 부드럽게 점멸한다.
- 경고음은 10초 전 1회, 종료 시 1회만 사용한다.
- 자동 진영 배정 또는 선택 화면 재시작 여부는 구현 전에 확정한다.

## 5. Phase 2 — 주장 작성

### 화면

- 개정 선언 말풍선이 사라진 뒤 주장 작성 창이 위에서 나타난다.
- 창 상단 왼쪽: `2단계 · 주장 작성`
- 창 상단 오른쪽: `03:00`
- 중앙: 큰 주장 입력란
- 입력란 안내: `사실관계에 근거하여 자신의 의견을 작성해 주세요.`
- 하단: `변론 제출`
- 작은 보조 버튼: `사건 기록`

### 사건 기록 팝업

- 데스크톱에서는 `사건 기록`에 마우스를 올리거나 키보드 포커스가 가면 표시한다.
- 클릭하면 팝업이 고정되고, 바깥을 클릭하거나 `Esc`를 누르면 닫힌다.
- 모바일에서는 hover가 없으므로 탭으로 열고 닫는다.
- 팝업에는 확정된 사실만 표시하고 AI 해석이나 법률 결론은 표시하지 않는다.

### 제출 후 재판장 문구

```text
양측의 의견 진술을 듣겠습니다.
```

### 제한시간 종료

- 시간 종료 30초 전과 10초 전에 타이머를 강조한다.
- 작성 중인 문장은 계속 자동 저장한다.
- 시간 종료 시 현재 입력을 자동 제출할지는 플레이테스트 후 확정한다.

## 6. Phase 3 — 양측 변론과 판정

Phase 3에는 제한시간을 표시하지 않는다. 큰 입력 창은 사라지고 법정 전체가 보인다.

### 6.1 검사 의견 진술

재판장:

```text
먼저 검사, 이 사건에 관한 최종 의견을 진술하시기 바랍니다.
```

검사 말풍선에 검사 측 변론을 2~4개 문장 단위로 나누어 표시한다.

### 6.2 변호인 의견 진술

재판장:

```text
다음으로 변호인, 최종 의견을 진술하시기 바랍니다.
```

변호인 말풍선에 변호인 측 변론을 2~4개 문장 단위로 나누어 표시한다.

### 6.3 변론 종결

재판장:

```text
양측의 의견을 모두 들었습니다. 이상으로 변론을 종결하겠습니다.
```

짧은 대기 연출 후:

```text
양측 변론에 대한 판정 결과를 말씀드리겠습니다.
```

### 6.4 판정 말풍선

승자가 있는 경우:

```text
이번 변론에서는 {검사/변호인} 측의 주장이 더 설득력 있다고 판단합니다.
```

무승부인 경우:

```text
양측의 주장이 비슷한 수준으로 인정되어 이번 변론은 무승부로 판정합니다.
```

실제 유·무죄를 선고하는 게임이 아니므로 다음 표현은 사용하지 않는다.

```text
피고인을 유죄로 선고합니다.
피고인을 무죄로 선고합니다.
징역 ○년에 처합니다.
```

## 7. 결과 화면

- 창 제목은 `재판 결과`보다 `변론 판정 결과`를 우선 사용한다.
- 가장 크게 `이번 변론 승자: 검사/변호인` 또는 `이번 변론: 무승부`를 표시한다.
- 아래에 `결정적 쟁점`, `판정 이유`, `사용한 판례·법령` 버튼을 순서대로 배치한다.
- 결과 창 뒤에는 법정과 세 캐릭터가 계속 보이게 한다.
- 재판장의 판정 말풍선이 끝난 후 결과 창을 표시한다. 둘을 동시에 띄우지 않는다.

## 8. 말풍선 규칙

- 한 말풍선은 최대 2~4개 문장으로 제한한다.
- 긴 변론은 클릭 또는 자동 재생으로 다음 말풍선으로 넘긴다.
- 현재 말하는 캐릭터만 살짝 밝게 하고 나머지는 원래 색보다 10~15% 어둡게 한다.
- 말풍선이 표시되는 동안 캐릭터에 과한 입 모양 애니메이션을 넣지 않는다.
- 사용자가 클릭하면 타이핑 애니메이션을 즉시 완료하고, 다시 클릭하면 다음 문장으로 이동한다.
- `주장하세요`, `말해보세요`, `판결을 내릴게요` 같은 일상적인 표현은 사용하지 않는다.

## 9. 기본 문구 치환표

| 사용하지 않을 문구 | 기본 문구 |
|---|---|
| `재판을 시작합니다.` | `이 사건에 대한 공판을 시작하겠습니다.` |
| `검사 측, 주장하세요.` | `먼저 검사, 최종 의견을 진술하시기 바랍니다.` |
| `변호인 측, 주장하세요.` | `다음으로 변호인, 최종 의견을 진술하시기 바랍니다.` |
| `판결하겠습니다.` | `양측 변론에 대한 판정 결과를 말씀드리겠습니다.` |
| `유죄/무죄입니다.` | `이번 변론에서는 ○○ 측의 주장이 더 설득력 있다고 판단합니다.` |

## 10. 참고한 실제 절차

대한민국 법원의 형사공판 안내에 따르면 증거조사와 피고인신문 뒤 검사가 의견을 진술하고, 이어 피고인과 변호인에게 최종 의견 진술 기회가 주어진 뒤 변론이 종결된다. 이 게임은 전체 형사공판을 재현하지 않고 그중 양측 최종 의견 진술 부분을 단순화하여 사용한다.
